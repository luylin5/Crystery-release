查看和渲染晶体与分子结构，模拟 PXRD 图谱，分析孔道；画好的图可以存进图库或工程文件，随时按原样打开。

本手册中 <strong>文件 › 导出 › CIF</strong> 表示：顶部菜单栏的“文件”，功能区中“导出”按钮的菜单里的“CIF”。

## <a id="start"></a>快速开始

1. <strong>打开结构。</strong>点 <strong>文件 › 打开 › 打开文件</strong>（<kbd>Ctrl</kbd>+<kbd>O</kbd>），或把文件拖进窗口，也可以在资源管理器中用“打开方式”选 Crystery。没有现成文件时用“新建结构…”（<kbd>Ctrl</kbd>+<kbd>N</kbd>）输入晶胞和原子。没有打开文件时，开始页列出最近打开的文件和图库中最近的绘图。
2. <strong>转动和选择。</strong>右键拖动旋转，滚轮缩放，<kbd>Ctrl</kbd>+右键拖动平移；左键单击选中原子，左键拖动框选。详见[鼠标与快捷键](#keys)。
3. <strong>调整画法。</strong>在“结构”中选球棍、棍状、空间填充、线框或热椭球；“显示”中选晶胞、完整分子或不对称单元、超胞和无序组分。每组按钮下方的标题（带 ⚙）打开这一组的详细设置。
4. <strong>出图。</strong>在 <strong>渲染</strong> 页的功能区中选 PyMOL（快）或 Mitsuba（真实感，较慢），点“渲染预览”看效果，再点“导出图片”。图片尺寸（宽、高、DPI、透明背景）在 <strong>渲染 › 尺寸 › 图片尺寸</strong> 中，三维画面中间的框就是渲染范围。
5. <strong>保存。</strong><kbd>Ctrl</kbd>+<kbd>S</kbd> 把当前绘图存进图库；要单独保存或发给别人，用 <strong>文件 › 工程 › 保存工程</strong> 存成一个 `.crystery` 文件。

> 从源码运行时，第一次启动会弹出“准备渲染环境”，为插件建立 Python 环境并安装组件（需要联网，只需一次）。便携版已自带，不需要这一步。

## <a id="ui"></a>界面概览

窗口的布局和 PowerPoint 相同：

- <strong>标题栏</strong>：左侧是撤销、重做按钮；中间是菜单栏（文件、结构、工具、渲染）；右侧是当前文件名（从图库打开时显示“图库 · 名称”，多结构文件还显示当前的数据块、帧或分子）、运行时的“运行中…”和版本号。
- <strong>进度窗口</strong>：渲染、导出、PXRD 模拟、孔道分析、检查结构等运行超过半秒时，窗口中间弹出进度窗口：正在做什么、用了多长时间，能算出进度时（PyMOL 景深虚化的帧、Mitsuba 的采样、Zeo++ 的各项计算、网格法的原子）显示百分比。点“取消”停止这次运行（连同它启动的 PyMOL、Mitsuba 或 Zeo++）。
- <strong>功能区</strong>：菜单栏下方，按用途分组的按钮。按钮多为图标，鼠标停在上面显示名称和说明；带 ▾ 的按钮会弹出选项菜单。窗口较窄时功能区可以左右滚动（也可以用滚轮）。
- <strong>左侧栏</strong>：一组按钮的详细设置。点这一组的任意按钮，或点组下方带 ⚙ 的标题，左侧栏就显示这一组的设置；正在显示的组有底色。再点一次标题、点左侧栏右上角的 ‹，或再点一次当前的菜单，收起左侧栏；点窗口左边缘的 › 重新展开。
- <strong>三维视图</strong>：中间区域，实时显示结构。右上角有“渲染预览”按钮。
- <strong>PXRD 图谱</strong>：计算后显示在三维视图下方，拖动上边缘调整高度，点 × 关闭。
- <strong>提示</strong>：右下角弹出的消息，点击即关闭。出错时为红色，鼠标停在上面可以看到详细的日志。

### 左侧栏的页面

| 菜单 | 页面（功能区中的组） |
| --- | --- |
| 文件 | 最近打开、图库 |
| 结构 | 模型、风格、原子、键（氢键、弱作用、多面体、芳环在左侧栏顶部切换）、标注、新增、显示范围、接触、显示效果（晶胞框）、背景、视角 |
| 工具 | PXRD、孔道 |
| 渲染 | 渲染器、导出图片、脚本、样式脚本 |

> <strong>数字输入框</strong>：留空的框以灰字显示当前实际使用的值（模型的、元素的、PyMOL 的……）。点上下箭头、滚动滚轮或输入时从这个值开始；不改动就仍是“未设置”。

### <a id="file-open"></a>打开与最近打开

- <strong>文件 › 打开 › 打开文件</strong>（<kbd>Ctrl</kbd>+<kbd>O</kbd>）：对话框中列出结构文件和 Crystery 工程（`.crystery`）。POSCAR、CONTCAR 这类没有扩展名的文件，把类型切换为“所有文件”。
- 拖进窗口：一次只打开一个结构；拖入多个文件时打开第一个能读的，并提示其余几个。不支持的格式会给出提示。
- <strong>文件 › 打开 › 最近打开</strong>：左侧栏列出最近打开的文件和工程，点击打开；鼠标指向时点 × 从列表中去掉；已经不存在的文件显示为灰色删除线。列表保留的个数在[偏好设置](#file-prefs)中设定（5～50，默认 20）。
- 再次打开同一个文件时，上次的显示设置（模型、范围、颜色、脚本……）会自动恢复。默认启动时还会重新打开上次的文件，可以在偏好设置中关掉。

### <a id="file-parts"></a>多结构文件（数据块、帧、分子）

一个文件里有多个结构时——CIF 的多个数据块、XYZ 的多帧、SDF 的多个分子——“打开”组后面多出一组，标题写明当前是第几个，例如“数据块（2/5）”：

- 点带 ▾ 的按钮，从列表中选要显示的一个；
- “上一个……”“下一个……”逐个切换。

每个数据块、帧或分子的显示设置分别记住。一个文件最多列出前 500 个。

### <a id="file-new"></a>新建结构

<strong>文件 › 打开 › 新建结构…</strong>（<kbd>Ctrl</kbd>+<kbd>N</kbd>）直接输入一个结构。对话框顶部先选<strong>晶体</strong>或<strong>分子</strong>。

<strong>晶体</strong>需要填写：

- <strong>名称</strong>：也是文件名。
- <strong>晶胞</strong>：a、b、c（Å，正数）和 α、β、γ（°，0～180 之间）。
- <strong>空间群</strong>：Hermann–Mauguin 符号（如 `P 21/c`、`Fm-3m`）或编号（1～230）。对称操作由程序按空间群补全。
- <strong>原子</strong>：不对称单元，每行一个原子：`标签 元素 x y z [占有率] [Uiso]`。x、y、z 是分数坐标，可以写成分数（如 `1/2`、`1/3`）；占有率和 Uiso（Å²）可以省略，占有率默认为 1。以 `#` 开头的行不读。标签不能重复。

例如 NaCl（空间群填 `Fm-3m` 或 `225`，a = b = c = 5.64）：

`Na1 Na 0 0 0`  
`Cl1 Cl 1/2 1/2 1/2`

<strong>分子</strong>不需要晶胞和空间群，只填名称和原子：每行 `元素 x y z` 或 `名称 元素 x y z`，x、y、z 是笛卡尔坐标（Å）。可以直接粘贴 XYZ 文件的内容（开头的原子数和注释行会跳过）。原子都没有名称时存为 XYZ；填了名称时存为 MOL2，以保留名称。例如水：

`O 0.000 0.000 0.117`  
`H 0.000 0.757 -0.469`  
`H 0.000 -0.757 -0.469`

点“保存并打开…”，选择保存位置：晶体存为 CIF，分子存为 XYZ 或 MOL2，保存后自动打开。输入有误时对话框中会指出是哪一行。

<strong>原子可以不填</strong>，得到一个空白的结构（晶体只有晶胞和空间群，分子什么也没有）。打开后在 <strong>结构 › 新增</strong> 中输入原子，或者从别的结构复制原子粘贴进来（见[复制和粘贴原子](#copy-atoms)）。

### <a id="file-project"></a>工程文件（.crystery）

工程文件把一张绘图存成<strong>一个文件</strong>，方便备份或发给别人：结构文件本身、显示设置、相机（方向、中心、缩放）、样式脚本，以及正在显示的孔道（计算结果和网格）；多结构文件还记下显示的是哪一个。

- <strong>保存工程</strong>：当前绘图是从工程打开的（或已存过工程），直接保存回这个工程文件；否则询问保存位置。
- <strong>另存工程…</strong>（<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd>）：总是存为新的工程文件。
- <strong>打开工程</strong>：用“打开文件”选 `.crystery` 文件，或从“最近打开”中点击，也可以在资源管理器中用“打开方式”选 Crystery。工程按保存时的样子恢复，孔道不需要重新计算。

工程文件和[图库](#gallery)保存的内容相同；区别在于图库是一个带缩略图的收藏夹，工程文件是单独的一个文件。

### <a id="file-export"></a>导出

点 <strong>文件 › 导出</strong>，在菜单中选择导出的内容。

- <strong>导出 › 结构文件</strong>：
  - <strong>XYZ、MOL2、PDB、SDF</strong>：导出当前*显示*的原子（随范围、超胞、生长而变）。PDB 在有晶胞时写入 CRYST1（空间群记为 P 1）。
  - <strong>CIF</strong>：导出晶体本身——晶胞、对称操作和不对称单元，与显示的范围无关；还写入空间群名称和编号、化学式、Z 和晶胞体积。
  - <strong>扩展 XYZ</strong>：导出一个晶胞，带晶格矢量（`Lattice=`），其他程序可以读；与显示的范围无关。
  - 分子（没有晶胞的文件）不能导出 CIF 和扩展 XYZ，这两项是灰的。
- <strong>导出 › 3D 模型</strong>：把画面中的原子、键、晶胞框、氢键和多面体按当前的方向存为三维模型：
  - <strong>glTF（.glb）</strong>：带颜色，PowerPoint、Blender 和网页三维查看器可以打开；
  - <strong>OBJ</strong>：同时存一个 `.obj` 和一个 `.mtl`（材质，即颜色），两个文件要放在同一个文件夹；
  - <strong>STL</strong>：用于 3D 打印，没有颜色，按 1 Å = 10 mm 缩放。原子超过 4000 个时，球和键用较少的面，以免文件过大。
- <strong>导出 › 矢量图</strong>：<strong>SVG</strong> 或 <strong>PDF</strong>：球和键画成可以编辑的图形，放大不失真；SVG 可在 Illustrator、Inkscape 中编辑，PDF 可直接插入论文。
- <strong>数据</strong>：文件中读出的表格和说明，例如“结构信息”“晶胞参数”“原子坐标”，CIF 还有“键长”；读文件时有需要注意的地方会有“提示”。点按钮在窗口中查看，表格可以“复制”后粘贴到 Excel。

图片的导出见[渲染 › 出图](#render-export)，图谱的导出见 [工具 › PXRD](#pxrd)。

### <a id="file-batch"></a>批量处理

<strong>文件 › 导出 › 批量处理…</strong> 逐个处理一个文件夹中的所有结构文件：

1. 选择<strong>输入文件夹</strong>（放结构文件的）和<strong>输出文件夹</strong>（保存结果的，可以新建一个）。
2. 勾选要输出的内容：
   - <strong>导出的结构格式</strong>：CIF（默认）、扩展 XYZ、XYZ、PDB、MOL2、SDF。XYZ、PDB、MOL2、SDF 写完整分子（框架结构为一个晶胞）；分子不写 CIF 和扩展 XYZ。
   - <strong>三维画面</strong>：每个结构存一张 PNG，用当前的显示设置；“三维画面的风格”选一种[预设风格](#render-styles)时，每个结构都按这种风格画。
   - <strong>结构检查</strong>：把每个结构的错误数、警告数写进汇总表。
   - <strong>汇总表</strong>：`汇总.csv`，每个结构一行：文件、化学式、Z、空间群和编号、晶胞参数和体积、独立位点数、错误和警告数、出错原因。可以直接用 Excel 打开。
   - <strong>文件含多个结构时每个都处理</strong>：CIF 数据块、XYZ 帧、SDF 分子逐个处理（每个文件最多 50 个）。
3. 点“开始”。窗口中逐行列出处理结果（✓ 成功，✗ 出错及原因）；点“停止”在当前结构处理完后停下。
4. 完成后点“打开输出文件夹”查看结果。

输出文件不会覆盖输入文件：输出文件夹与输入文件夹相同且文件名重复时，自动加上 `_crystery`，汇总表改名为 `Crystery_批量汇总.csv`。导出画面时会逐个显示各个结构，处理完后回到原来打开的绘图。

### <a id="file-prefs"></a>偏好设置与帮助

<strong>文件 › 选项 › 偏好设置</strong>：

- 启动时打开上次的文件（默认开）；
- 关闭窗口时，如果当前绘图改过还没保存，先提醒（默认开，见下文）；
- 启动时检查 GitHub 上有没有新版本（默认关）；
- 在画布左下角显示按下的键、鼠标点击的位置和它们的作用（默认开，见[鼠标与快捷键](#keys)）；
- 允许 AI 助手通过 MCP 操作 Crystery（默认关，只限本机）：打开后，支持 MCP 的 AI 助手可以连接 `http://127.0.0.1:39217/mcp`，在你看着的窗口里打开结构、调整显示和视角、写 PyMOL 命令、修改渲染设置、渲染和导出图片，每一步都显示在画面上（在 AI 助手的 MCP 设置中添加这个地址，传输方式选 HTTP）；
- 最近打开列表保留的文件数（5～50，默认 20）；
- 保存和打开对话框默认的文件夹（留空：上次打开的结构所在的文件夹）。

“恢复默认”把这些选项改回默认值。

<strong>文件 › 帮助</strong>：

- <strong>操作手册</strong>（<kbd>F1</kbd>）：在单独的窗口中打开本手册；
- <strong>新手引导</strong>：第一次启动时自动出现，逐个指出窗口的各个部分并说明用处（界面语言、菜单标签、打开文件、图库、三维画面的鼠标操作、模型、左侧栏、渲染器、图片尺寸、渲染预览与导出、PXRD 与孔道、设置与帮助）；用“上一步”“下一步”或方向键切换，Esc 或“跳过”结束，可以随时再打开；
- <strong>关于</strong>：版本号、插件版本和插件目录，以及 GitHub 发布页和作者主页的链接；
- <strong>检查更新</strong>：查询 GitHub 上的最新版本。有新版本时显示版本号、发布日期和更新说明，点“打开 GitHub 发布页”下载；已是最新时右下角提示。也可以直接访问[发布页面](https://github.com/luylin5/Crystery-release/releases/)。

### <a id="file-quit"></a>关闭前的提示

关闭窗口时，如果当前绘图的显示设置改过（有可以撤销的改动），且与上次保存到图库或工程时不同，Crystery 会先询问。只转动、缩放不算改动。三个按钮：

- <strong>第一个按钮保存后退出</strong>，按绘图的来源不同：
  - 从图库打开的：“更新图库中的这张图”；
  - 从工程打开或已存过工程的：“保存工程”；
  - 其他：“保存到图库…”。
- <strong>不保存，退出</strong>；
- <strong>取消</strong>：回到 Crystery。

不需要这个提示时，在偏好设置中取消“关闭窗口时……先提醒”。普通文件的显示设置本来就会自动记住，下次打开这个文件时恢复。

## <a id="model"></a>结构

- <strong>模型</strong>：球棍（默认）、棍状、空间填充、线框、热椭球。<strong>选中了原子时只改变选中的原子</strong>（组名显示“模型（N）”），例如把一个配体画成空间填充、其余仍是球棍；没有选中原子时改变全部原子，并去掉原子单独的模型。“恢复默认”在没有选中时回到球棍模型和默认尺寸，并去掉原子和键的单独设置；选中原子时让它们跟随全部原子的模型。右键原子 › 显示模式也可以设置。球的大小（× 半径）和椭球概率在左侧栏“原子”页点小球后设置，所有棍的半径在“键”页顶部。棍的半径留空时用模型自己的：棍状 0.18 Å、球棍 0.13 Å、热椭球 0.08 Å、线框 0.06 Å。
- <strong>原子</strong>：“去掉 H 原子”切换是否显示氢；“全部显示”恢复所有隐藏的分子、元素、位点和原子（颜色、大小等设置不变）。左侧栏是原子列表：每种元素一行。点小球弹出这一行的样式：模型（大球＝空间填充、小球＝球棍、热椭球，只改这种元素或位点的球，它的键（棍的有无和粗细）保持全部原子的模型画的样子，“跟随全部原子的模型”取消）、多面体（以这种元素为中心画配位多面体）和颜色，模型下面是它的设置（小球：这一行球的半径和所有小球的大小；大球：球的半径；热椭球：椭球概率；多面体：隐藏中心原子）。半径是现在的模型画出的球的半径（球棍为原子半径乘球的大小，空间填充为原子半径；棍状、线框、热椭球不画球时显示 –），换模型时跟着变，点它直接改这一行（淡色为元素的），[3] 是每个原子成键的原子数（周期性结构中，范围写成 [1 - 2]），右边的勾选框显示或隐藏；点 › 按位点单独设置，× 去掉单独的设置。点菜单栏的“结构”时左侧栏打开到这一组页面（上次看的那一页，第一次是“原子”），顶部可以在“原子 | 键 | 氢键 | 弱作用 | 多面体 | 芳环”之间切换；再点一次“结构”收起左侧栏。
- <strong>芳环填充</strong>：在左侧栏“芳环填充”页（左侧栏顶部的“芳环”）：勾选“填充芳环”填充所有芳环（PyMOL 的 cartoon 环面），取消勾选去掉；选中原子时只填充（或取消）它们所在的环，环上的原子都要选中。“芳环模式”选 PyMOL 画环的方式（环面、环面加键、球形等），还可以设找环方式、环面颜色和透明度。
- <strong>键</strong>：“自动成键”开关；“恢复自动成键”去掉所有元素对的规则。左侧栏可设成键容差；每对元素一张两行的卡片：第一行是棍的样子（点它选棍的半径）、两种元素、画面中的键数、“C → [0 - 3] N”（每个 C 原子与几个 N 原子成键）和是否成键；第二行是棍的半径和成键的最短–最长距离（直接改，留空为自动），最右的柱状图按钮显示这对元素在周期性结构中的距离分布，成键范围标为浅色，单击图中把较近的界限移到那里。
- <strong>氢键</strong>：左侧栏顶部的“显示氢键”勾选框打开或关闭氢键。和键一样，每种元素一张两行的卡片：第一行是氢键的样子（点它选虚线、圆头虚线、点线或实线和颜色）、H 和这种元素、画面中以它为受体的氢键数、找到的给体（如“N–H···O”）、D–H···A 最小角和是否作为给体或受体；第二行是氢键的半径、H···A 的距离范围（直接改最长距离）和 H 与这种元素的距离分布。距离、角度、半径、颜色和样式对所有氢键相同；虚线长度和间隔在卡片下面。
- <strong>弱相互作用</strong>：左侧栏顶部的“显示弱相互作用”勾选框打开或关闭弱相互作用（添加规则时自动打开）。在左侧栏选两种元素点“添加规则”（例如 C···O、Cl···Cl、C···H），每条规则是一张和键一样的两行卡片：虚线的样子（点它选这条规则的颜色和样式：虚线、圆头虚线、点线或实线）、两种元素、画面中的数目、范德华半径之和、×（删除）和是否使用；第二行是半径、最短和最长距离（直接改；新规则的最长距离默认是两种元素的范德华半径之和）和距离分布；距离在范围内的原子之间画一条虚线。相隔三个键以内的原子不算；“只画分子间”打开时（默认）同一分子内的也不算。可以对假原子（例如环的质心）设规则，画 π 相互作用。样式和半径对所有规则相同，虚线长度和间隔在卡片下面；导出的图片和 3D 模型中也有这些虚线。
- <strong>配位多面体</strong>：在左侧栏“多面体”页（左侧栏顶部的“多面体”）设置：“显示配位多面体”在中心原子周围画出多面体，顶点是与它成键的原子；选择哪些元素作为中心（“自动”为所有金属原子，顶点是与它成键的非金属原子；选了元素后，顶点是与它成键的其他元素的原子，例如选 O 可以画以阴离子为中心的多面体）；“隐藏中心原子”让中心原子和它的键不再画出，只留下多面体。也可以在“原子”页点某种元素的小球，选“多面体”以它为中心。顶点少于 4 个的不画。
- <strong>复制和粘贴原子</strong>：在视图中选中原子，按 <kbd>Ctrl</kbd>+<kbd>C</kbd>（或右键原子 › 复制）；然后打开另一个文件（或留在这个文件），按 <kbd>Ctrl</kbd>+<kbd>V</kbd>（或右键 › 粘贴原子）。粘贴的原子放在原来的笛卡尔坐标（Å）上，作为这个结构的新增原子：按对称性生成等价原子、自动成键、随文件保存，粘贴后被选中，可以用 <kbd>Ctrl</kbd>+<kbd>Z</kbd> 撤销。
  - 与已有原子重合、或与已有原子对称等价的原子不会重复添加，所以复制一个分子和它的对称等价原子，粘贴到同一空间群的晶体时只加一套。
  - 粘贴到分子中时，如果原来的位置在分子的范围外，粘贴的原子整体移到中间。
  - 剪贴板中的内容是文本（每行“名称 元素 x y z”），可以粘贴到记事本；反过来，从其他程序复制的“元素 x y z”或 XYZ 文件的原子行（Å）也能直接粘贴进来。
- <strong>删除原子</strong>：选中原子，按 <kbd>Delete</kbd>（或右键原子 › 删除）。晶体按对称性删除：删除的是选中原子所在的位点，与它对称等价的原子全部一起删除；分子直接删除选中的原子。删除的新增原子从列表中去掉，选中的假原子也一起删除。删除随文件保存，导出结构、PXRD 和孔道计算都不再包括删除的原子；按 <kbd>Ctrl</kbd>+<kbd>Z</kbd> 撤销，或者 <strong>结构 › 新增 › 清除 › 恢复删除的原子</strong> 一次恢复全部。
- <strong>假原子</strong>：新增原子和假原子在功能区的同一组（“新增”），左侧栏也是同一页：上面新增原子，下面假原子，分数坐标或笛卡尔坐标的选择两者共用；“清除”菜单分别清除新增原子或假原子。选中至少两个原子（例如一个芳环，<kbd>Ctrl</kbd> 加选），点“生成质心假原子”，在质心生成 Cg1、Cg2……（元素记为 X）。勾选“按对称性在所有等价位置生成”时，每个显示了对称等价原子组的地方都会出现对应的假原子。假原子可以和原子一起测距离、角度；“清除 › 清除假原子”全部删除，右键单个假原子可以删除它。

### <a id="model-select"></a>选择

- 在三维视图中单击原子、键、晶胞框或氢键选中；在 0.4 秒内再单击同一原子，选中整个分子。按住 <kbd>Ctrl</kbd> 或 <kbd>Shift</kbd> 加选。
- 左键拖动画框，框内的原子被选中（按住 <kbd>Ctrl</kbd>/<kbd>Shift</kbd> 加选）。
- 功能区“选择”组中的元素按钮选中所有该元素原子（<kbd>Ctrl</kbd> 加选）；“取消选择”或按 <kbd>Esc</kbd>、单击空白处取消。
- 选中原子后，左侧栏打开“原子”页，只列出选中的原子（按元素分行，标着“× 个数”），上方提示“只修改选中的 N 个原子”：这时点小球改模型、半径、颜色，或取消显示，只作用于选中的原子，未选中的不变（按元素选中时作用于这些元素）。选中键后打开“键”页，只列出选中的键（长度和粗细），改粗细只作用于它们（“选中同类键”时作用于这对元素）；选中氢键时打开“氢键”页。点提示里的“取消选择”或单击空白处，回到原来的页面和完整的列表。
- 左侧栏“选择与测量”可以按属性着色、调透明度、标签和测量线；“设置作用于”选全部原子或选中的原子。

### <a id="model-measure"></a>标签与测量

这一组的按钮都是下拉菜单，作用于选中的原子，没有选中时作用于全部：

- <strong>按属性</strong>：<strong>元素</strong>——颜色与左侧元素表一致（表中设置的颜色，没有设置时是样式脚本的颜色），可以把别的着色改回来；<strong>对称等价</strong>——同一个对称操作生成的分子同色，只差平移的也同色；<strong>分子</strong>——每个分子一种颜色；以及按位移参数 B、占有率（蓝→白→红）、分数坐标 x/y/z 或原子顺序（彩虹）着色。
- <strong>标签</strong>：原子名、元素、清除。标签在三维画面和渲染图中都画出来。
- <strong>测量</strong>：选“距离”“键角”或“二面角”后，在视图中依次<strong>点击</strong> 2、3 或 4 个原子（不需要按 <kbd>Ctrl</kbd>），测完自动开始下一次；视图中的提示条写着结果和下一步要点哪个原子。按 <kbd>Esc</kbd>、在没有选中原子时点空白处，或再选一次同一项结束测量。另有“质心”（在选中原子的质心放一个点）和“删除测量”。

标签字号和颜色、测量线的颜色和半径、距离的小数位在左侧栏“选择与测量”中设置。

### <a id="model-range"></a>显示与生长

- <strong>显示</strong>：范围：晶胞、完整分子、不对称单元；“超胞”菜单选 1×1×1、2×2×2、3×3×3、2×2×1，其他大小在左侧栏输入；“无序”菜单选显示哪些无序组分：全部、主组分（无序组 0 和 ±1）或次组分。左侧栏还可设边界原子、无序组分和碎片——取消勾选某种碎片（如溶剂分子）就把它隐藏。选择范围（包括再点一次当前的范围）会清除生长和接触生长加入的原子。
- <strong>生长</strong>：“生长”每点一次，加入与当前显示原子成键的下一层原子（鼠标指向按钮时显示次数）；“复原”撤销生长。要看被晶胞截断的分子的完整形状，在“显示”中选“完整分子”。
- <strong>接触</strong>：打开“显示接触”后，与显示的原子形成氢键或短接触（小于范德华半径之和加容差）的相邻原子画成淡色的球，用虚线连到显示的原子。<strong>单击淡色原子</strong>把它所在的整个分子加进来；“全部生长一层”一次加入所有接触；“撤销上一次”“清除”回退。左侧栏可选氢键、短接触和短接触容差。

分子（没有晶胞的文件）没有超胞和接触生长。

### <a id="view"></a>显示效果、背景与视角

- <strong>显示效果</strong>：晶胞框、晶轴（视图左下角显示 a、b、c 方向，渲染图中画成箭头）。晶轴和右上角的元素图例都可以用鼠标拖到别处，双击放回原处；拖动后的晶轴位置也用于导出的图片和渲染图。左侧栏设晶胞框的颜色和半径。配位多面体在 [模型](#model) 一组中。
- <strong>背景</strong>：白、灰、黑三种背景，“其他…”任选颜色；“跟随样式脚本”去掉设置的背景色，改用样式脚本的背景。芳环填充在左侧栏的“芳环”页中。“深度雾”按钮开关雾，左侧“背景与雾”设置雾浓度和雾起点：越远的部分越多地隐入背景色，三维画面和两种渲染器（PyMOL 风格、Mitsuba 风格）都用这套雾。灯光和轮廓在 [渲染 › PyMOL](#render-pymol) 中调节。
- <strong>视图</strong>：沿 a、b、c、a\*、b\*、c\* 方向观察；“重置”回到初始视角；“旋转”菜单绕屏幕 x、y、z 轴正反旋转一步，步长（5°～90°）在左侧栏“视角”中设置。左侧栏可输入任意晶格方向 [uvw] 或晶面 (hkl) 的法线。

## <a id="tools"></a>工具

“工具”菜单中是 PXRD 模拟和孔道分析，功能区分为 PXRD 和孔道两组。

## <a id="pxrd"></a>PXRD

从整个晶胞计算粉末衍射图谱，与当前显示的范围无关：IT92 原子散射因子、原子位移参数、洛伦兹-偏振校正、March–Dollase 择优取向、赝 Voigt 峰形。

1. 在 <strong>工具 › PXRD</strong> 的设置中选辐射（Cu、Mo、Co、Fe、Cr、Ag 的 Kα1/Kα 或自定义波长），设 2θ 范围、步长、半高宽、峰形 η，是否加入 Kα2、计入温度因子、不计 H，择优取向方向和 March–Dollase 系数，单色器角度。
2. 点“计算 PXRD”。图谱显示在结构下方（图谱已显示时再点一次重新计算）；之后修改设置或打开其他结构，图谱自动重新计算。
3. 需要对比时，<strong>工具 › PXRD › 叠加…</strong> 读入实验数据（XRDML、RAS 或两列数据 .xy/.xye/.txt/.dat/.csv/.asc），一次可选多个文件；“清除”去掉它们。实验图谱的波长与计算的不同时会提示。

### 查看和导出图谱

- 在图谱中拖动选择 2θ 范围放大，滚轮缩放，双击复原；鼠标指向峰时显示 hkl、d、强度和多重度。
- 图谱上方可勾选“峰位刻线”“hkl 标注”“实验图谱错开”。
- 图谱区右上角的 × 关掉它，“计算 PXRD”再显示出来；“峰列表”查看所有衍射峰（可复制）；“导出 XY”“导出峰表”（CSV）“保存图片”（PNG）。

分子没有晶胞，不能计算 PXRD。

## <a id="pores"></a>孔道

按周期性结构计算孔道（跨越晶胞边界的孔道完整计算），孔道画在显示的晶胞（含超胞）内：蓝色是贯穿晶体的孔道，橙色是探针进不去的封闭孔穴。

1. 点 <strong>工具 › 孔道 › 显示孔道</strong>，左侧栏上面是“计算”的设置，先选择方法：
   - <strong>Zeo++</strong>：给出孔径 Di/Df/Dif、孔道数和维度、比表面积、孔体积、孔径分布。可设采样精度（默认“精细”；可占据孔体积 POAV 是随机采样，采样点少时偏低）和高精度（-ha）；Zeo++ 程序留空时自动查找（便携版已自带）。
   - <strong>网格法</strong>：在网格上计算空穴和孔隙体积，不需要 Zeo++。
2. 选孔隙表面（接触面，或探针中心能到达的溶剂可及面）和探针：常见气体（He、H₂O、H₂、CO₂、Ar、N₂、CH₄、Xe）或自定义半径；网格间距 0 为自动。
3. “只计入主无序组分”和“去掉范围面板中隐藏的碎片”默认打开，避免无序原子或溶剂分子堵住孔道。先在 [结构 › 显示](#model-range) 的碎片中隐藏溶剂，计算时就不算它们。
4. 点左侧栏中的“计算孔道”（算过后是“重新计算孔道”）。

### 显示和结果

- <strong>工具 › 孔道</strong>：“显示孔道”“网格线”“封闭孔穴”开关（还没有计算时，“显示孔道”只打开左侧栏）；左侧栏下面的“显示”调表面位置（接触面向内收或等值面距离）、表面平滑、孔道和孔穴的颜色、不透明度。这些只改变显示，不重新计算。
- <strong>工具 › 孔道 › 结果表</strong>：左侧栏列出全部数值（可复制）和孔径分布图。
- <strong>工具 › 孔道 › 导出 Zeo++ 结果</strong>（结果表下面也有这个按钮）：用 Zeo++ 方法算过后，把 Zeo++ 自己输出的文件存到选择的文件夹，按结构名命名，和直接运行 Zeo++ 得到的一样：`.res`（孔径 Di/Df/Dif）、`.chan`（孔道）、`.sa`（比表面积）、`.vol`（孔体积）、`.volpo`（可占据孔体积）、`.psd_histo`（孔径分布），以及输入的 `.cssr`。
- 显示中的孔道会一起画进渲染预览、导出图片和导出会话，也随图库和工程文件保存。

分子没有晶胞，不能分析孔道。

## <a id="render"></a>渲染

“渲染”页的功能区中，<strong>尺寸</strong>一组是两种渲染器都用的图片尺寸和虚化（景深），点按钮在左侧栏中调节。<strong>PyMOL</strong> 和 <strong>Mitsuba</strong> 各是一个大图标：点它就选用这个渲染器（选中的图标高亮），左侧栏显示它自己的设置，顶部的标签（如 Mitsuba 的 材质 | 轮廓 | 灯光 | 环境 | 发光 | 质量）切换各页。数值用滑块或直接输入，颜色用取色器或输入 #rrggbb，“默认”清除颜色。“渲染预览”和“导出图片”都使用所选的渲染器。

<strong>虚化（景深）</strong>（尺寸组，两种渲染器共用）：勾选后设虚化强度、对焦（画面中心或选中的原子）、焦点前后移动和帧数（8～64，只用于 PyMOL）。Mitsuba 用真实的镜头；PyMOL 本身没有景深，是把镜头绕焦点稍转后拍多帧叠加而成，虚化越强需要的帧越多，否则能看出分层。

### <a id="render-styles"></a>预设风格

把一个结构调好的画法存起来，打开别的结构点一下就画成同样的样子（和图片尺寸的 1:1、4:3 一样，只是可以自己保存）。<strong>结构 › 风格 › 保存风格…</strong>，起个名字，选风格中包含的内容：

- <strong>模型与显示</strong>：模型、球和棍的大小、元素的颜色、配位多面体、氢键样式、晶胞框和晶轴、投影，以及 PyMOL 的灯光、轮廓、背景、雾、芳环填充、按元素或按属性着色、标签等命令。
- <strong>渲染器设置和样式脚本</strong>：选用的渲染器和它的全部设置（虚化、材质、灯光、环境、质量）。
- <strong>图片尺寸</strong>（默认不含）：宽度、高度、DPI、透明背景。

应用：<strong>结构 › 风格 › 应用风格</strong>、左侧栏的风格列表，或右键菜单的“预设风格”。“默认”回到插件自带的画法。风格不改变结构本身的东西：范围、超胞、隐藏的分子和元素、单独设置的位点和原子、对选中原子的着色和测量都保留。模型与显示的改动可以用 Ctrl+Z 撤销。左侧栏中每种风格可以“更新”（用当前设置替换）、重命名、删除。[批量处理](#file-batch)导出三维画面时也可以选一种风格。

### <a id="render-pymol"></a>PyMOL（光线追踪）

和三维画面一致，出图快。

- <strong>灯光与阴影</strong>：环境光、直射光、反射光、镜面高光、高光锐度、光源数、双面光照、阴影。
- <strong>轮廓与抗锯齿</strong>：光追模式（普通、加黑色轮廓、只有轮廓线、色块加轮廓）、轮廓粗细和颜色、抗锯齿。

前两节的设置写成 PyMOL 命令记在脚本里，三维画面也随之改变。雾照着 <strong>结构 › 背景</strong> 的深度雾画，和三维画面一致。

### <a id="render-mitsuba"></a>Mitsuba（路径追踪）

软阴影、反射、玻璃折射都按物理计算，效果更真实，出图较慢。

- <strong>材质</strong>：光泽塑料、哑光、金属、玻璃。
- <strong>轮廓</strong>：在前后错开的地方（物体边缘、前后重叠处）描线。可调粗细（随图片大小缩放）和颜色（默认黑色）；雾里同样变淡。
- <strong>灯光</strong>：摄影棚、柔和、戏剧，或 HDR 环境贴图（.hdr/.exr）。预设灯光可整体水平旋转、抬高，调整光源大小、环境光和色温；环境贴图只能水平旋转和调色温。
- <strong>环境</strong>：背景、背景板（接住阴影，默认开）、曝光补偿。背景默认是三维画面的背景颜色（结构 › 背景），也可以选预设图片（浅灰渐变、深色聚光、深蓝渐变、暖色晕影、天空）或自定义图片（.png/.jpg 等，铺满画面，多出的部分裁掉）；有背景板时阴影落在背景图上。雾跟随三维画面，淡入背景；透明背景时不画背景，雾让远处渐渐变透明。
- <strong>发光</strong>：选中的部分自己发光，照亮周围并带一圈光晕。可选发光的原子（元素、选中的原子或全部；发光的是原子的球）、键（写 Cu 为 Cu 的所有键，写 Cu-O 只要这种键）、配位多面体（按中心元素）以及氢键、弱作用、晶胞、孔道、封闭孔穴、表面（PyMOL 的分子表面）、芳环；输入框下的按钮可点选。可调发光强度（1 与白色表面一样亮）、光晕大小（0 为不加光晕）和发光颜色（留空用各自的颜色）。深色背景上效果更明显。
- <strong>质量</strong>：预览 64、标准 256、精细 1024 次采样；计算设备“自动（先试 GPU）”或“只用 CPU”。

> 便携版已自带 Mitsuba。从源码运行时，第一次使用前点 <strong>渲染 › 样式 › 安装 Mitsuba 渲染器</strong>（需要联网，约 50 MB）。

### <a id="render-export"></a>出图、画面与脚本

- <strong>出图</strong>：“渲染预览”用所选渲染器渲染当前画面，盖在视图上（视图右上角也有这个按钮）；“导出图片”按“图片尺寸”的宽×高（像素）、DPI 和透明背景出图。和 Blender 的相机框一样，三维画面中间画出这个长宽比的渲染框（框外变暗），渲染预览就是要导出的图（同样的尺寸和设置，缩小后盖在框上），画面和设置没变时“导出图片”直接保存它；高度留空时不用渲染框，按三维画面的长宽比出图。
- <strong>视频</strong>：“渲染视频”按左侧设置的运动逐帧渲染渲染框里的画面，每一帧都用所选的渲染器和它的全部设置出图，存成 MP4 视频（H.264）或 PNG 图片序列。运动可以是旋转（绕屏幕的竖直轴、水平轴、视线，或绕晶轴 a、b、c；360° 的整数倍时首尾相接，可以循环播放）、来回摇摆，或从当前视角出发依次经过“结构 › 视图”中保存的视角；还可以在结束时放大、缓入缓出。设置时长、帧率（24、30、60 帧/秒）和视频宽度（高度按渲染框的长宽比）。进度卡片显示正在渲染第几帧，可以随时取消；PyMOL 每帧通常一两秒，Mitsuba 每帧都要完整路径追踪，较慢。透明背景只用于 PNG 图片序列。
- <strong>画面</strong>：“复制渲染图”（没有选中原子时按 <kbd>Ctrl</kbd>+<kbd>C</kbd>）把渲染出来的图按原尺寸复制到剪贴板，和“导出图片”保存的一样；还没有当前画面的渲染预览时先渲染。“复制画面”把三维画面复制到剪贴板，“保存画面”存为 PNG，它们是画面截图，不经过渲染。
- <strong>会话</strong>：“导出会话”把同一场景存为 `.pse`，可以在 PyMOL 中打开继续编辑。
- <strong>脚本</strong>：左侧栏的脚本在样式脚本之后执行，侧边栏的大多数操作都会写成 PyMOL 命令记在这里。可以直接修改后点“运行”（<kbd>Ctrl</kbd>+<kbd>Enter</kbd>），“撤销上一条”删掉最后一条命令，“清空”全部去掉；下方的命令行输入一条命令回车执行（`sele` 为选中的原子）。
- <strong>样式</strong>：“样式脚本…”指定自己的 `.pml`/`.py` 样式脚本，留空时用插件自带的默认样式；“检查渲染环境和样式脚本”报告环境是否正常；“安装 Mitsuba 渲染器”见上。

## <a id="gallery"></a>图库

图库收藏画好的图：保存时连同结构文件、显示设置、视角和缩放、样式脚本、显示中的孔道、接触生长的分子和假原子一起存下；打开时按原样恢复，原文件之后移动或修改都不受影响。

- <strong>保存</strong>：<strong>文件 › 图库 › 保存到图库</strong>（<kbd>Ctrl</kbd>+<kbd>S</kbd>，或右键菜单），填写名称和备注。
- <strong>打开</strong>：<strong>文件 › 图库 › 打开图库</strong>（<kbd>Ctrl</kbd>+<kbd>G</kbd>）打开大窗口，或点组标题在左侧栏查看缩略图；点缩略图打开。可按名称、文件或备注搜索。
- <strong>更新</strong>：从图库打开后继续修改，“更新这张图”覆盖原图；“保存到图库”则另存一张。
- <strong>每张图的按钮</strong>：打开、重命名（名称和备注）、导出图片（另存保存时的画面为 PNG）、删除（移到回收站，可恢复）。
- <strong>位置</strong>：“打开文件夹”在资源管理器中打开；“更改位置…”换到其他文件夹（例如云盘同步文件夹）；“刷新”重新读取。

每张图是图库文件夹中的一个子文件夹，包含 `entry.json`、结构文件、样式脚本、保存时的画面和缩略图、孔道网格。

## <a id="faq"></a>常见问题

- <strong>PXRD、孔道、超胞的按钮是灰的？</strong> 打开的是分子（文件中没有晶胞），这些功能需要晶胞。
- <strong>原子不见了，怎么找回？</strong> 点 <strong>结构 › 模型 › 全部显示</strong>，或右键菜单“隐藏 › 全部显示”。也检查“去掉 H 原子”、范围中的碎片和无序组分，以及视图中的“剪切平面”。
- <strong>转动时不小心框选了原子？</strong> Crystery 用<strong>右键</strong>转动，左键用来选择和框选。单击空白处或按 <kbd>Esc</kbd> 取消选择。
- <strong>测量时点原子没有反应 / 想停止测量？</strong> 先在 <strong>结构 › 标注 › 测量</strong> 中选距离、键角或二面角，再依次点原子；视图中的提示条会写出下一步。按 <kbd>Esc</kbd> 结束。
- <strong>Mitsuba 出图很慢，或提示采样数比设定的少？</strong> 每次渲染限时约 2 分钟，时间到了就用已有的采样出图，提示中写出实际采样数。可以先用“预览”质量调好画面，再用标准或精细出最终图。用不了 GPU 时提示会写出原因（常见的是需要更新 NVIDIA 驱动）；装了 LLVM 后 CPU 渲染会快很多。
- <strong>景深虚化能看出分层？</strong> PyMOL 的虚化是多帧叠加：增加帧数，或减小虚化强度。时间不够时会少拍几帧，提示中写出实际帧数。
- <strong>孔道计算提示找不到 Zeo++？</strong> 在孔道设置中指定 `network.exe` 的位置，或改用“网格法”，它不需要 Zeo++。便携版已自带 Zeo++。
- <strong>孔道被溶剂或无序原子堵住了？</strong> 保持“只计入主无序组分”和“去掉范围面板中隐藏的碎片”打开，并在 <strong>结构 › 显示</strong> 左侧栏的碎片中取消勾选溶剂分子，再重新计算。
- <strong>叠加的实验图谱和计算的峰对不上？</strong> 检查两者的辐射波长：实验图谱记录了波长而与计算的不同时，Crystery 会提示。在 PXRD 设置中改成相同的辐射或自定义波长。
- <strong>按 <kbd>Ctrl</kbd>+<kbd>Z</kbd> 没有撤销画面的改动？</strong> 光标在输入框中时，<kbd>Ctrl</kbd>+<kbd>Z</kbd> 撤销的是输入。点一下三维视图再按，或用标题栏左侧的撤销按钮。转动和缩放不在撤销范围内。
- <strong>图库想放到别的地方或多台电脑同步？</strong> 用 <strong>文件 › 位置 › 更改位置…</strong> 选一个文件夹（例如云盘同步文件夹）。要把一张图发给别人，用“保存工程”存成一个 `.crystery` 文件更方便。
- <strong>每次关闭都问要不要保存？</strong> 只有绘图的显示设置改过、还没存进图库或工程时才会问，见[关闭前的提示](#file-quit)。不需要时在 <strong>文件 › 选项 › 偏好设置</strong> 中关掉。
- <strong>第一次运行时 Windows 提示“未知发布者”？</strong> 程序没有代码签名。点“更多信息 → 仍要运行”。
- <strong>便携版的数据存在哪里？</strong> 设置和输出在程序旁边的 `Crystery-data`，默认图库在 `Crystery 图库`，整个文件夹可以拷走。程序所在文件夹不能写入时（例如 Program Files），改放在 `%APPDATA%\Crystery`。

Crystery 用于查看和渲染晶体与分子结构。当前版本显示在主窗口标题栏的右侧（软件版本 · 插件版本），也可以在 <strong>文件 › 帮助 › 关于</strong> 中查看（还有插件目录）；用“检查更新”查询新版本，或到 [Crystery 发布页面](https://github.com/luylin5/Crystery-release/releases/) 下载。

Crystery 使用了以下开源软件，感谢它们的作者：

- [PyMOL（开源版）](https://github.com/schrodinger/pymol-open-source)：画面、PyMOL 风格渲染和会话；
- [Mitsuba 3](https://www.mitsuba-renderer.org/)：Mitsuba 风格的路径追踪渲染；
- [gemmi](https://github.com/project-gemmi/gemmi)：空间群和原子散射因子；
- [NumPy](https://numpy.org/)：数值计算；
- Zeo++：孔道分析；
- [3Dmol.js](https://3dmol.csb.pitt.edu/)：三维视图；
- [Electron](https://www.electronjs.org/)：桌面程序框架。
